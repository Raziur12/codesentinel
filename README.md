## Overview

CodeSentinel is an enterprise-grade AI platform that automatically scans, analyzes, validates, debugs, tests, and evaluates software projects before production deployment.

Instead of checking one file at a time, CodeSentinel understands the complete application architecture.

---

## Core Features

- Multi Repository Support
- ZIP Upload
- Local Workspace
- GitHub Integration
- AI Root Cause Analysis
- Automatic Technology Detection
- Build Validation
- Runtime Validation
- Security Analysis
- Performance Analysis
- Production Readiness Report
