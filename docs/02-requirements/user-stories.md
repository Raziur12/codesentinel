# User Stories

## Developer

As a developer, I want to upload my project so that CodeSentinel can analyze it before production.

---

## QA Engineer

As a QA engineer, I want a complete validation report so I can reduce manual testing effort.

---

## DevOps Engineer

As a DevOps engineer, I want deployment validation before releasing to production.

---

## CTO

As a CTO, I want production readiness scores for every release.
